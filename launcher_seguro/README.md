# Launcher seguro

Execute com Python 3:

```bash
python launcher.py
```

O programa abre no máximo uma página por execução: o site solicitado ou a
página oficial de download do Opera ou do XAMPP. Baixar e instalar os programas
é uma ação manual do usuário. Para criar um executável Windows, instale o
PyInstaller e execute `pyinstaller --onefile launcher.py` nesta pasta.
